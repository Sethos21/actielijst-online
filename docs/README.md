# docs/

Referentiemateriaal uit de oorspronkelijke planningsfase van dit project
(vóór de omzetting naar React + Vite + Firebase). Bewaard omdat het de
functionele eisen, het datamodel en de huisstijl beschrijft die nog steeds
gelden — ook al is de technische aanpak inmiddels anders dan hier staat
beschreven.

- **BVC_INSTRUCTIE_v02.md** — oorspronkelijke werkinstructie (schrijft nog
  een single-file HTML + localStorage-aanpak voor; inmiddels vervangen door
  React + Firebase, zie de PR-geschiedenis voor die beslissing). De
  functionele prioriteiten, teamleden-lijst en datastructuur zijn nog steeds
  van toepassing.
- **BVC_WEBAPP_PROJECT_v03.md** — projectdocument met de volledige
  functionele scope: Module 1 (Actielijsten) en Module 2 (Huurdersmutaties),
  inclusief openstaande/nog te bouwen onderdelen.
- **BVC_UI_UX_DESIGN.md** — design-tokens, componenten en UX-principes,
  geëxtraheerd uit `bvc_actielijst_v17.html`. Leidend voor de huisstijl in de
  React-versie.
- **bvc_actielijst_v17.html** — de laatste werkversie van de oorspronkelijke
  single-file HTML-prototype (localStorage, geen backend). Dient als
  functionele/visuele referentie, wordt niet meer actief doorontwikkeld.
